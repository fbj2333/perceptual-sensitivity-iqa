图像质量评估

像素变化 ≠ 感知质量差异：一个区域依赖、语义驱动的非线性 Gap

文献调研与研究方案报告

2026 年 3 月

一、研究动机

核心问题

像素级变化量 ≠ 人类感知质量差异。这两者之间的 gap 是区域依赖、语义依赖、且高度非线性的。

同一 seed、同一 prompt 生成的两张图像，构图完全一致，但细节不同：

面部：微妙的眼部畸变

像素差异：~2%
感知影响：恐怖谷效应，极其严重
人类评分变化：−40 分

↔

背景：轻微锐度下降

像素差异：~5%
感知影响：几乎不可察觉
人类评分变化：−2 分

现有 IQA 方法（LPIPS、NIQE、TOPIQ，甚至基于 VLM 的方法）本质上在衡量"变化了多少"，而非"这个变化对人来说重要吗"。

二、现有模型的缺陷证据

A-Bench (ICLR 2025)：LMM 质量感知的系统性失败

A-Bench 测试了 23 个大型多模态模型在 2,864 张 AIGC 图像（16 个 T2I 模型）上的评估能力：

评估维度最佳 LMM
(Qwen2-VL-72B)		最差人类差距
语义理解86.02%88.50%−2.5%
质量感知（整体）68.99%83.61%−14.6%
 技术质量74.22%94.32%−20.1%
 美学质量60.31%84.49%−24.2%
 生成畸变70.23%86.25%−16.0%

关键结论：最差的人类标注者仍比最好的 LMM 高出 14.6%。质量感知是 LMM 的根本性短板，不是模型规模问题。

A-Bench 未覆盖的问题：它问的是"有没有噪声？"（是/否），即"图像有没有某种问题"。它不回答"这个问题对人的感知影响有多大"——这正是我们的切入点。

三、核心洞察

AIGC 中感知质量是 Prompt 条件化的

同样的视觉特征，在不同 prompt 下质量含义完全不同：

Prompt 信号隐含的质量期望传统 IQA 判定
"vintage film grain"噪点是期望特征噪声 → 低分
"tilt-shift miniature"选择性模糊是期望特征模糊 → 低分
"dreamy soft portrait"柔焦是期望特征模糊 → 低分
"glitch art"像素错位是期望特征严重伪影 → 极低分
"bokeh background"背景模糊是期望特征背景模糊 → 扣分
"8K macro photography"要求极高清晰度锐利 → 高分（恰好一致）

这不是风格分类问题，而是开放域语义理解问题。只有 LLM 能从任意自然语言 prompt 中推理出质量评判准则。

TSP-MGS (2024) 暴露了社区盲区

TSP-MGS 在评估感知质量时，明确用固定模板 "A photo of {adj} quality" 替代用户原始 prompt——假设感知质量与 prompt 无关。对非写实内容系统性误判。

四、数据构造

同 Seed 受控变体数据库

设计原则：锁定构图，只变细节质量。产生最干净的感知灵敏度研究信号。

与现有数据集对比

数据集数据策略是否受控
A-Bench (ICLR'25)30K 图 → 人工挑选有问题的图否（大海捞针）
AGIQA-3K / AIGIQA-20K不同 prompt × 不同模型否（所有变量混杂）
AGHI-QA (2025)400 prompt × 10 模型，身体部位标注否（不同图像）
本方案同 seed → 变 CFG / VAR 退出是（仅细节质量变化）

数据源 1：CFG Scale 变体

  • 同 seed、同 prompt，不同 CFG scale
  • 低 CFG → 细节缺失；高 CFG → 过饱和/artifacts
  • 构图不变，细节完成度连续渐变

数据源 2：VAR 提前退出

  • VAR = coarse-to-fine 逐级生成（NeurIPS'24 最佳论文）
  • 提前退出 = 自然的细节缺失（"还没画完"）
  • 比合成退化或 diffusion 噪声中间步更接近真实 AIGC 质量问题

标注方式

标注者看到同 seed 的一组变体 → 评估各变体整体感知质量分 + 区域感知质量分 → 标注数据天然编码感知灵敏度 ground truth（脸部变化导致 40 分差 vs 背景变化导致 2 分差）。

五、方法概述

整体架构

输入: (AIGC 图像, 用户 Prompt) │ ├─→ LLM (质量准则推理器) │ ├─→ quality_criteria: {可接受: [...], 缺陷: [...]} │ ├─→ 实体列表 + 区域重要性先验 │ └─→ 感知灵敏度提示 (portrait → 面部高敏感) │ ├─→ Grounding DINO 1.6 + SAM2 → 区域 mask │ ├─→ 视觉编码器 → 多尺度特征 │ └─→ 准则条件化 + 灵敏度感知的质量模型 │ │ 对每个区域: │ · 提取区域特征（全局上下文 + 局部细节） │ · 结合准则条件评分（噪点在 vintage 下不扣分） │ · 输出区域感知质量分 │ ├─→ 区域分: {面部: 0.30, 手部: 0.70, 背景: 0.90} │ └─→ 语义感知聚合 → 整体分: 0.42 (面部低分主导整体，因为 portrait prompt → 面部高灵敏度)

Prompt 的双重角色

  1. 质量准则定义—— "vintage film grain" → 噪点可接受
  2. 灵敏度调制—— "portrait" → 面部区域灵敏度极高

非线性聚合

  • 面部 0.3 + 背景 0.9 → 整体 0.42（面部主导）
  • 面部 0.9 + 背景 0.5 → 整体 0.82（背景影响小）

聚合函数本身编码了人类感知灵敏度偏好。

五、方法概述（续）

为什么 LLM 不可替代

从任意 prompt 推理质量准则是开放域语义推理任务：

替代方案能推理 "tilt-shift → 选择性模糊可接受" 吗？
风格分类器不能——无法覆盖组合语义
CLIP 嵌入不能——只做相似度匹配，不具备推理能力
关键词匹配不能——无法理解 "dreamy" 暗示"允许柔焦"
LLM可以——从任意自然语言推理质量准则

LLM 输出示例

Prompt: "a dreamy soft portrait of a girl holding vintage flowers, bokeh background" LLM 输出: { "quality_criteria": { "acceptable": ["皮肤柔焦", "低对比度", "背景模糊"], "defects": ["面部畸变", "手部变形", "不自然皮肤纹理"] }, "entities": ["女孩面部", "手部", "复古花束", "背景"], "sensitivity": {"面部": "极高", "手部": "高", "花束": "中", "背景": "低"} }
五、方法概述（续）

准则 × 区域协同效应

质量准则与区域定位不是独立的——它们在每个区域上交互：

示例："dreamy soft portrait of a girl, bokeh background"

区域视觉特征适用准则评分影响
背景模糊"bokeh expected"不扣分
面部柔焦"dreamy → 轻微柔焦可接受"轻微扣分
面部五官畸变"面部畸变 = 缺陷"严重扣分
手部手指变形"手部变形 = 缺陷"严重扣分

只有同时知道"这是哪个区域"和"prompt 对这个区域的期望是什么"才能正确评分。同一张图中，背景模糊不扣分，面部模糊要扣分。

实用价值：可操作的反馈

现有方法

"整体质量: 0.6"
→ 该改哪里？不知道。

→

我们的方法

"手部: 0.3 (变形), 面部: 0.85, 背景: 0.9"
→ 对手部做 inpainting。

七、技术挑战

核心技术挑战

1. 非线性灵敏度建模

模型需从数据中学会：

  • 面部微小变化 → 大幅扣分（恐怖谷）
  • 背景微小变化 → 几乎不扣分
  • 手部变形 → 中到重度扣分

灵敏度分布应从标注中自然涌现，非预设规则。

2. 语义感知聚合

区域分 → 整体分不是面积加权平均：

  • 面部=0.3, 背景=0.9 → 整体 ~0.4
  • 面部=0.9, 背景=0.5 → 整体 ~0.8

聚合函数编码感知灵敏度偏好。

3. Prompt 双重引导

  • 灵敏度调制："portrait" → 面部权重 ↑
  • 质量准则："vintage" → 噪点可接受

4. 容忍度边界

"vintage film grain" 允许噪点但不允许色彩严重失真。
"dreamy" 允许柔焦但不允许几何变形。
模型需学会风格容忍与真实缺陷的边界。

八、贡献

贡献总结

1. 问题定义

指出 AIGC 质量评估中"像素变化 ≠ 感知差异"的 gap——该 gap 区域依赖、语义依赖、高度非线性。现有指标根本无法捕捉这一关系。

2. 受控变体数据集（数据贡献）

首个同 seed 受控变体 AIGC 质量评估 benchmark——构图锁定，仅细节质量变化（CFG scale 变体 + VAR 提前退出）。区域级人工感知质量标注提供灵敏度 ground truth。

3. 灵敏度感知质量模型（方法贡献）

  • 从受控变体标注数据中学习人类感知灵敏度的非均匀分布
  • LLM 推理 prompt 条件化质量准则 + 灵敏度调制
  • 语义感知的区域分非线性聚合

4. 验证实验

  • 证明现有方法（NR-IQA + VLM-based）在同 seed 变体上排序与人类感知严重不一致
  • 证明当前 MLLM 无法区分"面部微小变化（影响大）"和"背景大幅变化（影响小）"

十、可行性评估

可行性与风险

评估维度状态
问题新颖性已确认——无已有工作覆盖
数据构造可行——CFG 变体生成简单；VAR 推理快速
标注成本中等——同 seed 分组使标注更高效
技术实现可行——成熟组件（Grounding DINO, SAM2, VLM backbone）
实验验证设计清晰——受控变体使测量精确
与 AGHI-QA 竞争方向不同——他们检测畸变，我们建模灵敏度

主要风险

  • LLM 准则稳定性——准则生成需要一致性，可能需要 few-shot 模板或微调
  • 容忍度边界模糊——"风格允许的变异"与"真实缺陷"本身存在模糊地带
  • 标注一致性——区域级感知评分的标注者间一致性可能低于全图评分
总结

总结

问题：像素变化 ≠ 感知质量差异。这一 gap 是区域依赖、语义依赖、高度非线性的。现有方法无法建模。

数据：首个同 seed 受控变体 AIGC 质量 benchmark——构图锁定，仅变细节质量——配合区域级人工感知标注。

方法：LLM 推理质量准则 + 区域 grounding + 灵敏度感知的非线性质量模型，从受控变体中学习人类感知灵敏度分布。

意义：将 AIGC 质量评估从"变化了多少"推进到"人类是否在意这个变化"。
