Motivation: The Core Problem

Pixel-level change ≠ Human perceptual quality difference.
This gap is region-dependent, semantically-dependent, and highly non-linear.

Same seed, same prompt — two images with identical composition but different details:

Face: subtle eye distortion

Pixel difference: ~2%
Perceptual impact: Devastating (uncanny valley)
Human score drop: −40 pts

↔

Background: slight sharpness loss

Pixel difference: ~5%
Perceptual impact: Barely noticeable
Human score drop: −2 pts

Existing IQA methods (LPIPS, NIQE, TOPIQ, VLM-based) measure how much changed, not whether humans care about the change.

Insight: Perceptual Quality is Prompt-Conditioned

The same visual feature can be acceptable or a defect, depending on the prompt:

Prompt SignalImplied Quality ExpectationTraditional IQA Judgment
"vintage film grain"Noise is expectedNoise → low score
"tilt-shift miniature"Selective blur is expectedBlur → low score
"dreamy soft portrait"Soft focus is expectedBlur → low score
"glitch art"Pixel displacement is expectedSevere artifact → very low
"bokeh background"Background blur is expectedBackground blur → penalized
"8K macro photography"Extreme sharpness requiredSharp → high score (matches)

This is not a style classification problem — it is an open-domain semantic reasoning problem. Only an LLM can infer quality criteria from arbitrary natural language prompts.

TSP-MGS (2024) Exposes the Community's Blind Spot

TSP-MGS explicitly discards the original prompt during perceptual quality evaluation, replacing it with a fixed template "A photo of {adj} quality". This assumes perceptual quality is prompt-independent — demonstrably wrong for non-photorealistic content.

Data: Same-Seed Controlled Variant Benchmark

Design Principle

Fix composition. Vary only detail quality. This yields the cleanest possible signal for studying perceptual sensitivity.

Comparison with Existing Benchmarks

BenchmarkData StrategyControlled?
A-Bench (ICLR'25)30K images → manually pick problematic onesNo (needle in haystack)
AGIQA-3K / AIGIQA-20KDifferent prompts × different modelsNo (all variables mixed)
AGHI-QA (2025)400 prompts × 10 models, body-part annotationNo (different images)
OursSame seed → vary CFG / VAR exitYes (only detail quality varies)

Source 1: CFG Scale Variants

  • Same seed, same prompt
  • CFG low → detail loss; CFG high → over-saturation
  • Composition unchanged, detail quality gradient

Source 2: VAR Early Exit

  • VAR = coarse-to-fine next-scale prediction (NeurIPS'24 Best Paper)
  • Early exit = natural detail deficiency ("not yet finished")
  • More realistic than synthetic degradation or noisy diffusion intermediates

Annotation

Annotators see same-seed variant groups. Rate: per-region perceptual quality + overall score. Focus on perceptual quality, not semantic alignment. Annotations naturally encode the perceptual sensitivity ground truth.

Method Overview

Input: (AIGC Image, User Prompt) | |--- LLM (Quality Criteria Reasoner) | |--- quality_criteria: {acceptable: [...], defects: [...]} | |--- entities + region importance priors | '--- sensitivity hints (portrait -> face hypersensitive) | |--- Grounding DINO 1.6 + SAM2 -> region masks | |--- Vision Encoder -> multi-scale features | '--- Criteria-Conditioned, Sensitivity-Aware Quality Model | | Per region: | - Extract features (global context + local detail) | - Condition on criteria (noise OK under "vintage") | - Output regional perceptual quality score | |--- per-region scores: {face: 0.30, hands: 0.70, bg: 0.90} | '--- Semantic-aware aggregation -> overall: 0.42 (face dominates because portrait prompt -> face high-sensitivity)

Key: Two Roles of Prompt

  1. Quality Criteria — "vintage film grain" → noise acceptable
  2. Sensitivity Modulation — "portrait" → face region hypersensitive

Key: Non-Linear Aggregation

  • face 0.3 + bg 0.9 → overall 0.42 (face dominates)
  • face 0.9 + bg 0.5 → overall 0.82 (bg barely affects)

The aggregation function itself encodes human perceptual sensitivity.

Why LLM is Irreplaceable

Inferring quality criteria from arbitrary prompts is an open-domain semantic reasoning task:

AlternativeCan it reason "tilt-shift → selective blur OK"?
Style ClassifierNo — can't cover combinatorial semantics
CLIP EmbeddingNo — no reasoning, only similarity matching
Keyword MatchingNo — can't understand "dreamy → soft focus OK"
LLMYes — can reason from any natural language prompt

LLM Output Example

Prompt: "a dreamy soft portrait of a girl holding vintage flowers, bokeh background" LLM output: { "quality_criteria": { "acceptable": ["soft focus on skin", "low contrast", "background blur"], "defects": ["facial distortion", "hand deformation", "unnatural texture"] }, "entities": ["girl's face", "hands", "vintage flowers", "background"], "sensitivity": {"face": "very high", "hands": "high", "flowers": "medium", "bg": "low"} }

Criteria × Region Synergy

Quality criteria and region grounding are not independent — they interact per-region:

Example: "dreamy soft portrait of a girl, bokeh background"

RegionVisual FeatureApplicable CriteriaScore Impact
BackgroundBlurry"bokeh expected"No penalty
FaceSoft focus"dreamy → slight softness OK"Minor penalty
FaceDistorted features"facial distortion = defect"Heavy penalty
HandsDeformed fingers"hand deformation = defect"Heavy penalty

Only by knowing both "which region" and "what the prompt expects for this region" can the model score correctly. Background blur is fine; face blur is not — in the same image, under the same prompt.

Key Technical Challenges

1. Non-Linear Sensitivity Modeling

The model must learn from data:

  • Face micro-change → massive score drop
  • Background micro-change → negligible
  • Hand deformation → moderate-to-severe

This should emerge from annotations, not be hard-coded.

2. Semantic-Aware Aggregation

Region scores → overall score is not area-weighted average:

  • face=0.3, bg=0.9 → overall ~0.4
  • face=0.9, bg=0.5 → overall ~0.8

The aggregation function encodes perceptual sensitivity.

3. Prompt Dual Guidance

  • Sensitivity modulation: "portrait" → face weight ↑
  • Quality criteria: "vintage" → noise OK

4. Tolerance Boundaries

"Vintage film grain" allows noise but not color corruption.
"Dreamy" allows soft focus but not geometric distortion.
The model must learn where style tolerance ends and defect begins.

Contributions

1. Problem Definition

We identify that pixel-level change ≠ perceptual quality difference in AIGC images, and this gap is region-dependent, semantically-dependent, and highly non-linear. Existing metrics fundamentally fail to model this.

2. Controlled-Variant Benchmark (Data)

The first same-seed controlled variant benchmark for AIGC quality assessment. Composition is fixed; only detail quality varies (CFG scale variants + VAR early exit). Region-level human perceptual quality annotations provide ground truth for sensitivity modeling.

3. Sensitivity-Aware Quality Model (Method)

  • Learns human perceptual sensitivity distribution from controlled-variant data
  • Prompt-conditioned quality criteria + sensitivity modulation via LLM reasoning
  • Semantic-aware non-linear region-to-overall aggregation

4. Motivation Experiments

  • Demonstrate existing methods (NR-IQA + VLM-based) rank same-seed variants inconsistently with human perception
  • Demonstrate current MLLMs cannot distinguish "small face change (high impact)" from "large background change (low impact)"

Summary

Problem: Pixel change ≠ perceptual quality difference. The gap is region-dependent, semantically-dependent, and non-linear. Current methods fail to model this.

Data: First controlled-variant AIGC quality benchmark — same seed, only detail quality varies — with region-level human perceptual annotations.

Method: LLM-reasoned quality criteria + region grounding + sensitivity-aware non-linear quality model trained on controlled variants.

Impact: A new paradigm for AIGC quality assessment — from "how much changed" to "how much humans care."
